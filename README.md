# Ashen Relay 公開計画

このリポジトリは現時点の全作業計画を公開するGitHub Pages用の静的サイト。`index.html` は入口、`world.md`、`gameplay.md`、`mods.md`、`ideas.md`、`seams.md`、`delivery.md`、`implementation.md`、`completion.md` は詳細ページの編集元。`python3 render.py` で詳細HTMLを更新する（`markdown-it-py` が必要）。

実装と検証の正本は非公開の `docs/FOUNDATION.md`、`docs/IMPLEMENTATION_BLUEPRINT.md`、`docs/LONG_TERM_ROADMAP.md`、`docs/COMPLETION.md`。計画が変わったら内部の決定とこのサイトを同時に更新する。物語の核心・ローカルパス・ログ・認証情報は掲載しない。
