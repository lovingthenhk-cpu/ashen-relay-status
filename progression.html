趣旨との照合（2026-10-23 再読後）

原要求は、複数Modの強敵/素材/技/建築を接続し、拾った新しい武器へ投資を移し、別の場所で組合せを試すゲームを作ること。レシピを長くすることや既存Modの完成品一覧を埋めることを目的にしない。

  • 各製作経路に「組み合わせるMod要素」「新しく可能になる操作」「別圏で使う場面」「前の武器から移す強化」を書く。材料名と個数だけでは設計完了にしない。
  • 五空間型の試験は終盤体験の最初の型。六圏18場面や追加Mod案を五つの部屋へ縮約しない。通常/熟練/達人は調整案であり、同じ部屋の反復を新しい場面数に数えない。
  • 残響精錬・武器台帳・地区共鳴・戦技再演・継ぎ目異常・部分継承を製作/攻略の選択へ接続する。素材回収だけの周回で埋めない。
  • 工場で得た部品は継承や磁気装備、ボス技の再利用へつなぐ。低価値材の消費レシピ2件だけで横断装備設計を完了にしない。
  • 複数の攻略順と装備の更新先を維持する。他Modの建築/敵/技は部品として借り、元のストーリー/案内/攻略順は移管・停止する。都市外の環境例外には都市からの往復導線を付ける。

1. まず現状を正す

  • 独自レシピは現在、研究石板・空の継承印・継承触媒の3件。元Modに横断合成や武器強化はあるが、全施設の入手量と製作目標を一体で設計した状態ではない。
  • 工場の容器Lootは実装・代表検証済み。ただし「素材が存在し用途がある」だけでは経済設計の受入にしない。現Lootは仮配分として扱い、本書の用途・数量・次の攻略への接続を満たしてから調整完了とする。
  • 以下の確定は採用するゲーム設計という意味。新しいレシピ、報酬保証、複合戦、案内が既に動くという意味ではない。今回production設定、コード、既存worldは変更しない。
  • 素材・武器の事実確認は固定jarの41レシピと12Loot表の静的抽出に基づく。固定版データから入出力とLootを確認。runtimeでの全経路開通・実ドロップ率・難度は別途検証する。

6. 箱・ボス報酬を製作目標から逆算する

  • 道中箱は生活材/装備更新材/希少な副抽選に役割を分ける。工場の回収材が目立つ場合でも、入口時点で「空印・交通・装備のどれに使えるか」を表示する。
  • 設計初期値: 工場を一棟探索した時、回収材版空印2個（swarf8/精髄4/紙2）と、古代槍1本（金属4）を目標にできる配分。素材全量を一施設に集約せず、精髄/紙は都市の別寄り道でも補える。工場12箱のうち古代金属6箱×1～3は既存配分で6～18。回収材/精髄は抽選で不足するため、用途確定後に総量を補正する。
  • 必須進行の鍵と初回の署名巻物は保証/進捗で取得し、希少抽選だけにしない。非必須上位装備も、初回攻略後の有限・確定な再取得経路を追加する。方式は対応ボスの再戦実績と専用報酬であり、日用品を万能通貨にしない。
  • 再取得は地区共鳴(U03)で対応する攻略先/報酬を狙う経路、武器台帳(U02)と既存撃破/接合記録で観測済みの候補を表示する方式から設計する。元ドロップを保持し、通常素材の万能交換へ変えない。先に提示した「対応ボス3回で1個」は未測定の候補へ差戻し、必須の固定周回回数として確定しない。既存状態で安全に表現できない場合だけ追加の保存責務を設計し、各素材の有限・確定な再取得が成立するか検証する。
  • 高位素材は製作品ごとの必要数と入手条件を表示する。4系列全部の必要数を一つの必須ノルマへ足さない。工場Lootを良くするために他ボスの完成武器や最終素材を道中箱へばらまかない。
  • 既存開封箱の補充/既存worldの書換えはしない。新規箱・新規取得経路へ適用する。

8. 旧案・拡張Modを何に使うか

六圏・18場面・58縫合・W/S/G/U/P/N/Xの既存採用行は削除しない。追加Modを調べる際も本書の消費先へ接続する。

  • X01 Apoli / X02 Ars / X06 Hex: 魔術/境界試験の発射形・条件・狙点と再演。P2から提示、P5で組み替える。
  • X03 IE / X05 Mekanism / X07 Pneumatic / X08 Create / X09 IF / X15 CC・ID: 工業の液体・弾・汚染・設備・観測。P2～P3の装備準備と設備攻略、P5の別解。各Modの全工業化を必須にはしない。
  • X04 Occultism / X11 Botania / X14 EvilCraft: 高位継承・境界準備の代替資源/儀式。P3/P5へ。中断・回収と旧装備の安全を守る。
  • X10 Twilight / X12 Aether / X13 Ice and Fire: 環境に応じた別攻略・別技の獲得をP3/P5へ。都市入口からの導線、必要環境の例外理由、元ストーリー停止を個別判断。
  • X16 Dungeons Enhanced / X18 Graveyard / X19 WDA / X20 Integrated WDA: 都市景観と攻略先の種類をP0～P5に配分。建物数だけ増やさず各場所に更新先を置く。
  • X17 Simply Swords/Integrated: 主副武器の器を各段階へ追加し継承互換を確認。旧「カテゴリが足りるから不採用」は現行の除外理由にしない。

未導入の各方式は固定版/権利/互換/停止手段の試験待ち。試験前から既存終盤への必須素材にしない。失敗時も狙った操作・経路を別部品へ引き継ぎ、工数だけで削らない。
